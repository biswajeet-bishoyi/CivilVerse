# Welcome

Thank you for contributing to CivilVerse.

Our goal is to build the world's most comprehensive AI-powered civil engineering knowledge platform through high-quality engineering, documentation, and collaboration.

---

# Core Values

- Education first
- Technical accuracy
- Respectful collaboration
- Documentation-driven development
- Continuous improvement
- Long-term thinking

---

# Ways to Contribute

- Documentation
- Frontend development
- Backend development
- AI systems
- Engineering content
- UI/UX design
- Testing
- Accessibility
- Localization
- Bug reports
- Feature proposals

---

# Development Workflow

1. Create an issue.
2. Discuss the proposal.
3. Create a feature branch.
4. Implement changes.
5. Add or update documentation.
6. Submit a pull request.
7. Address review comments.
8. Merge after approval.

---

# Branch Naming

- feature/<name>
- fix/<name>
- docs/<name>
- refactor/<name>
- chore/<name>

---

# Commit Convention

- feat:
- fix:
- docs:
- refactor:
- test:
- chore:
- perf:

---

# Pull Request Checklist

- Builds successfully
- Lint passes
- Tests pass
- Documentation updated
- Accessible UI
- No console errors
- Screenshots included (if UI changes)

---

# Coding Standards

- TypeScript
- Strict typing
- Reusable components
- Meaningful naming
- Small pull requests
- Clear comments where intent is not obvious

---

# Documentation

Every significant feature should include:

- Purpose
- Requirements
- Architecture impact
- Testing notes
- Future improvements

---

# Community Expectations

Be respectful.

Provide constructive feedback.

Assume positive intent.

Welcome new contributors.
