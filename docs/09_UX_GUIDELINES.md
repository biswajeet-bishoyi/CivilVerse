**Project:** CivilVerse

# UX Vision

CivilVerse should make complex civil engineering concepts feel intuitive, engaging, and enjoyable to explore.

---

# UX Principles

- Learn by exploring
- Show before telling
- Minimize cognitive load
- Progressive disclosure
- Consistency across modules
- Accessibility by default

---

# Primary User Journeys

## Student
Home

→ Learn module
→ Ask Archie
→ Take quiz
→ Save notes

## Professional
Search
→ Engineering reference
→ Standards guide
→ Calculator
→ Bookmark

## Researcher
