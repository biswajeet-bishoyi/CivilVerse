# Purpose

This file provides persistent project context for AI assistants contributing to the CivilVerse repository.

## Project Summary

CivilVerse is an AI-first civil engineering knowledge platform.

It combines:

- Engineering encyclopedia
- Interactive learning
- Infrastructure explorer
- Engineering news
- AI assistant (Archie)
- Engineering calculators
- Career resources

## Vision

Build the world's most comprehensive civil engineering knowledge ecosystem.

## Development Principles

- Quality over speed.
- Education first.
- Accuracy over assumptions.
- Modular architecture.
- Accessibility by default.
- Mobile-first responsive design.
- Performance-conscious engineering.
- Security-first mindset.

## Coding Standards

- TypeScript only
- Strict mode enabled
- Reusable components
- Functional React components
- Server Components by default
- Client Components only when required
- Zod validation
- ESLint + Prettier
- Clear naming conventions

## Preferred Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- PostgreSQL
- Prisma
- Supabase
- OpenAI
- Vercel AI SDK
- Meilisearch
- Mapbox
- React Query

## AI Guidelines

Archie should:

- Explain instead of merely answering.
- Encourage learning.
- Cite authoritative sources where appropriate.
- Acknowledge uncertainty.
- Avoid unsafe engineering recommendations.
- Adapt explanations to user experience level.
