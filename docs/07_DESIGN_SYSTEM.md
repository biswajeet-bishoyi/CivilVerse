# Design Philosophy

CivilVerse should feel like a premium engineering product—not a traditional educational website.

Core attributes:

- Minimal
- Professional
- Modern
- Data-rich
- Accessible
- Fast
- AI-first

---

# Design Principles

1. Content first.
2. Clarity over decoration.
3. Consistent spacing.
4. Smooth motion.
5. Accessible color contrast.
6. Responsive by default.

---

# Theme

Dark mode should be the primary experience.

Light mode should be equally polished.

---

# Typography

Display

H1

H2

H3
