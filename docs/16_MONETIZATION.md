# Monetization Strategy

CivilVerse should become a sustainable business while keeping high-quality engineering knowledge broadly accessible.

---

# Principles

- Education first
- No intrusive advertising
- Transparent pricing
- Value-driven subscriptions
- Free core learning experience

---

# Revenue Streams

## Free Tier

- Public articles
- Basic search
- Limited Archie usage
- Core calculators

## CivilVerse Pro

- Unlimited Archie
- Advanced calculators
- Research summaries
- Learning paths
- Saved workspaces
- Export features

## Student Plan

Discounted access for verified students.

## Team Plan

Shared workspaces

Organization management

Usage analytics

## Enterprise

- SSO
- Custom branding
- Admin dashboard
- API access
- Dedicated support

---

# Additional Opportunities

- Certification programs
- Sponsored engineering webinars

- Recruiter tools

# Monetization Guardrails

Never:

- Sell user conversations
- Gate essential educational content
- Overload pages with ads
- Compromise AI quality for revenue

---

# KPIs

- Free → Pro conversion
- Monthly recurring revenue
- Retention
- Customer lifetime value
- Churn
- Average revenue per user
